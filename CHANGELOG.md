# Changelog

## 1.0.1

* New app icon: exe, window, taskbar, Start menu and desktop shortcuts, and the entry in Settings > Apps.

## 1.0.0

First public release.

### Disk usage
* Whole-partition scan in one pass with a live, animated progress view.
* Disk map: every folder as a tile sized by its share of the partition, click to drill in.
* Fast parallel scanner, plus optional **Fast mode** that reads the NTFS master file table (administrator).
* Quick access, partitions list, folder contents list, breadcrumb, drag and drop, command-line folder argument.

### Charts
* 2D charts: disk map, storage growth flow chart, summary gauge, folders by size, file types, largest files, modified-by-month heatmap, 24-month activity, size distribution, file age, added per year, space by category, files vs file size, files over time, activity by category.
* 3D charts: folder spheres, largest-file pins, activity terrain (drag to rotate).
* Cards grouped into **2D charts** and **3D charts** sections.
* Hover animation: cards float and replay their own animation; GPU-cached for smooth hovering.

### Apps & games
* Installed apps and games from Steam, Epic, Xbox and the Windows program list, with the size of the program and the size of its data (estimated by folder name).
* Filter, sort, search; click to open the install folder.

### Live sensors
* CPU and GPU temperature and power, once a second.
* Windows of 1, 5, 30 minutes and 1, 12, 24 hours, with average, peak and energy used.
* GPU works without administrator rights; CPU needs them.

### App
* Light and dark theme.
* MSI installer and portable exe.
